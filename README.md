# La6_game3d

Godot 4.7 3D lab: an island scene with simple trees and animated characters.

This is an animation demo. The characters animate automatically; there are no player movement controls.

## Run locally

Import `project.godot` in Godot 4.7 and press F5.

## Browser build

The `docs/` directory contains the Web export. GitHub Pages can serve it from the `main` branch, `/docs` folder.

The Web build uses the Compatibility renderer and disables threads.
To rebuild, install the Godot 4.7 export templates and export the Web preset to `docs/index.html`.
